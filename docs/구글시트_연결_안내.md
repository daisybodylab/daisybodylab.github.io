# 몸 체크리스트 · 제휴 문의 → 구글 시트(엑셀) 자동 정리 연결 안내

홈페이지 체크리스트의 **'결과 보내기'**와 제휴 페이지의 **'제휴 제안 보내기'**를 누르면, 하나의 구글 시트에 한 줄씩 자동으로 쌓입니다.
- `체크리스트 응답` 탭: 몸 체크리스트 결과
- `제휴 문의` 탭: 제휴 제안 양식

주소 하나만 연결하면 두 곳 모두 저장됩니다.
엑셀 파일이 필요할 때는 시트에서 바로 내려받으면 됩니다. 처음 한 번만 설정하면 되고, 10분 정도 걸립니다.

---

## 1. 시트 만들기
1. 센터용 구글 계정으로 [Google 드라이브](https://drive.google.com)에 들어갑니다.
2. **새로 만들기 → Google 스프레드시트**를 누르고, 이름을 `데이지 홈페이지 접수`로 바꿉니다.

## 2. 스크립트 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본으로 있는 내용을 모두 지우고, `docs/google-apps-script/Code.gs` 파일 내용을 그대로 붙여 넣은 뒤 저장(💾)합니다.
3. 위쪽 함수 선택 칸에서 `setupTest`를 고르고 **실행**을 누릅니다.
4. 권한 요청 창이 나오면 센터 계정으로 **허용**합니다. ('확인되지 않은 앱' 안내가 나오면 **고급 → 이동**을 누르면 됩니다. 직접 만든 스크립트라서 나오는 안내입니다.)
5. 시트로 돌아가 `체크리스트 응답`, `제휴 문의` 두 탭에 초록색 머리글 줄이 생겼는지 확인합니다.

## 3. 웹 앱으로 배포하기
1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. **실행 사용자: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정하고 **배포**를 누릅니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 홈페이지에 연결하기
`data/site-data.js` 파일의 `checklistEndpoint` 따옴표 안에 복사한 주소를 붙여 넣습니다.

```js
checklistEndpoint: "https://script.google.com/macros/s/여기에_복사한_주소/exec",
```

저장하면 두 곳이 함께 바뀝니다.
- 체크리스트 결과 화면에 **'센터에 결과 미리 보내기'** 칸이 나타납니다.
- 제휴 페이지 양식에 **개인정보 동의 칸**이 생기고, 버튼이 **'제휴 제안 보내기'**로 바뀝니다. (카카오톡 문의 버튼은 옆에 그대로 남아요.)

각각 직접 한 번 보내 보고, 시트의 두 탭에 줄이 추가되는지 확인하세요.

> 제휴 문의를 **다른 시트**에 따로 받고 싶다면, 그 시트에도 같은 스크립트를 설치·배포한 뒤 주소를 `partnershipEndpoint`에 넣으면 됩니다.

## 5. 보관 기한이 지난 응답 자동 삭제 (꼭 설정)
개인정보처리방침의 보관 기간(기본 1년)이 지나면 지워야 합니다.
1. Apps Script 왼쪽의 **시계 아이콘(트리거) → 트리거 추가**를 누릅니다.
2. 실행할 함수: `deleteExpired` / 이벤트 소스: **시간 기반** / 유형: **일 단위 타이머**로 저장합니다.
3. 보관 기간을 바꾸려면 `Code.gs`의 `RETENTION_DAYS`와 처리방침 문구를 함께 바꿔 주세요.

## 6. 엑셀 파일로 받기
시트 메뉴 **파일 → 다운로드 → Microsoft Excel(.xlsx)**을 누르면 됩니다.
'상담 상태' 칸은 목록(새 접수 · 연락 완료 · 상담 예약 · 등록 · 보류)에서, 제휴 문의의 '진행 상태' 칸은 목록(새 접수 · 연락 완료 · 미팅 예정 · 진행 중 · 완료 · 보류)에서 골라 관리할 수 있습니다.

## 7. 새 접수 알림 메일 (선택)
`Code.gs`의 `NOTIFY_EMAIL = '';` 따옴표 안에 메일 주소를 넣으면, 접수될 때마다 알림 메일이 옵니다.
체크리스트는 건강 정보를 메일에 넣지 않고 '새 접수가 있다'는 사실과 시트 링크만 보냅니다. 제휴 문의는 단체·회사명과 제휴 분야까지 함께 보냅니다.

> **이미 예전 버전 스크립트를 배포해 두셨다면:** `Code.gs` 내용을 새 파일로 통째로 바꿔 붙여 넣고 `setupTest`를 한 번 실행한 뒤, 아래 방법으로 새 버전을 배포해 주세요. 웹 앱 주소는 그대로라서 홈페이지는 고칠 필요가 없습니다.
코드를 바꾼 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다.

## 8. 꼭 지켜 주세요 (개인정보 보호)
- 시트는 **담당자에게만 공유**하고, 링크 공유는 끄세요.
- 센터 구글 계정에 **2단계 인증**을 켜 두세요.
- 홈페이지의 `privacy.html`(개인정보처리방침)에서 대괄호 [ ] 항목을 채우고, 공개 전에 전문가 검토를 받으세요.
- 고객이 삭제를 요청하면 시트에서 해당 줄을 바로 지워 주세요.
